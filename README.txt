CASH ESCAPE: THE MISSING MONEY CASE
=================================

CARA MENJALANKAN
1. Ekstrak ZIP ini.
2. Buka folder CASH_ESCAPE_GAME.
3. Klik dua kali index.html untuk membuka game di browser.
4. Untuk multiplayer online, kedua pemain perlu koneksi internet. Satu pemain memilih Buat Room, lalu pemain lain memasukkan nama room dan password yang sama dan memilih Gabung Room.
5. Di PC: gerak dengan WASD atau tombol panah, tekan E untuk memeriksa bukti.
6. Di HP: gunakan tombol arah dan tombol PERIKSA. Saat layar portrait, tampilan game diputar otomatis ke landscape 16:9 pada browser yang mendukung transformasi viewport.

CATATAN
- Multiplayer memakai PeerJS dan memerlukan internet serta layanan PeerJS publik; jaringan/firewall tertentu dapat memblokir koneksi.
- Game memakai canvas 2D dengan efek perspektif/faux-3D, bukan model 3D sungguhan.
- Musik ambient dibuat secara sintetis tanpa lirik.
- Kunci jawaban tidak ditampilkan pada panel pertanyaan. Logika jawaban tetap berada di JavaScript sisi browser, sehingga bukan sistem ujian yang aman dari inspeksi kode.
- Untuk hasil terbaik di HP, buka melalui browser modern dan aktifkan layar penuh bila tersedia.
